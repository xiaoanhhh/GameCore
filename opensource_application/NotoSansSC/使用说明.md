## 重建步骤

日常构建直接使用已提交的子集，不需要下载原始字体。新增中文文案时：

1. 从上面的固定提交下载原始 TTF 到根目录 `.cache/font-source/NotoSansSC-variable.ttf`。
2. 用 `Get-FileHash` 核对源文件 SHA-256。脚本也会再次检查，不接受未知源文件。
3. 在具备 Python 和 [FontTools 4.63.0](../FontTools/使用说明.md) 的环境中执行 `python scripts/prepare-lobby-assets.py`。
4. 提交更新后的子集和字符表，运行图形任务检查字形。

脚本先生成临时字体并计算内容哈希。已有相同产物时校验后跳过，否则创建新文件，再原子替换字符表和清单。这几个文件之间没有跨文件事务保证。

## 限制

- 子集不覆盖全部汉字。玩家昵称等用户自定义内容超出字符表时，需要扩大字符集或改用完整字体。
- 字体图集由 libGDX FreeType 生成，由 `ClientAssetManager` 释放。五图场景版本的展示字体在密度 1.0 / 1.25 时实测为 3 / 4 页（12 / 16 MiB），这不是总显存峰值。
