## 作用

从 Noto Sans SC 可变字体生成项目使用的字体子集：正文字重 450（GameCore UI Sans）和展示字重 900（GameCore Display）。

## 调用方式

`scripts/prepare-lobby-assets.py` 调用 `TTFont`、`instantiateVariableFont` 和 `Subsetter`：

1. 扫描 `client`、`game-tank`、`game-fight` 主源码中的字符。
2. 生成静态字重和字符子集，修改衍生字体的名称。
3. 固定字体头的时间戳，避免只因构建时间不同而改变产物。
4. 按内容哈希命名文件，写入独立清单。

同一脚本用 Python 标准库 `wave` 合成原创的试听音。

## 限制

只有重建素材时才需要 Python 和 FontTools，Java 和 Gradle 运行不依赖它们。更新工具版本后要重新检查字体外观和字符覆盖，转换成功不等于排版正确。

验证方法：源字体哈希检查、子集 cmap 覆盖检查、真实 FreeType 字形检查。
