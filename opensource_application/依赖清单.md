# 依赖清单

Java 21。Maven 依赖的版本由 [libs.versions.toml](../gradle/libs.versions.toml) 固定，平台服务的版本由 Spring Boot BOM 管理。每个项目的许可、用法和限制见各自目录。

## 怎样核对

运行、测试、构建三类依赖要分开看，不能混为一谈：

```powershell
.\gradlew.bat :lwjgl3:dependencies --configuration runtimeClasspath --console=plain
.\gradlew.bat :lwjgl3:dependencies --configuration testRuntimeClasspath --console=plain
.\gradlew.bat :game-server:dependencies --configuration runtimeClasspath --console=plain
.\gradlew.bat :platform-service:dependencies --configuration runtimeClasspath --console=plain
```

新增或升级依赖时，核对实际解析的版本、所在配置和许可，更新对应目录和本表，并重跑受影响的测试。本清单不是漏洞扫描结论。
