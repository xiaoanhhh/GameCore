# gdx-jnigen loader

| 项目 | 内容 |
| --- | --- |
| 制品 | `com.badlogicgames.gdx:gdx-jnigen-loader:2.5.2` |
| 类型 | 客户端运行依赖（gdx 1.14.2 传递引入） |
| 许可 | POM 声明 Apache-2.0 |
| 来源 | [libgdx/gdx-jnigen](https://github.com/libgdx/gdx-jnigen) |

libGDX 用它查找和加载本地库。项目不直接调用 loader API，也不执行 jnigen 代码生成。

验证方式是桌面图形任务：图形和 Pixmap 的本地接口实际工作。POM 元数据见上级 `dependency-metadata.json`。

该 JAR 没有内嵌 LICENSE，正式发行时要从上游补齐许可资料。
