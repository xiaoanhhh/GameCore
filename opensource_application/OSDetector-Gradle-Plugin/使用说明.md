# OS Detector Gradle Plugin

| 项目 | 内容 |
| --- | --- |
| 制品 | `com.google.gradle:osdetector-gradle-plugin:1.7.3` |
| 类型 | 构建工具依赖（`protobuf-gradle-plugin` 0.10.0 传递引入） |
| 许可 | Apache-2.0，原文见 [LICENSE](LICENSE) |
| 来源 | [官方源码](https://github.com/google/osdetector-gradle-plugin/tree/v1.7.3) |

Protobuf 插件用它的操作系统和架构 classifier 选择 `protoc` 二进制。它再依赖 `kr.motd.maven:os-maven-plugin:1.7.1`。只存在于 Gradle 构建类路径，不进入运行 JAR。

实际验证过的平台是 Windows x86_64，能检测到某个平台不代表那个平台已经测试过。依赖链报告见 build-dependencies.txt，升级 Protobuf 插件时要重新核实。
