## 作用

为云主机的公网 IP 申请和续期 HTTPS 证书。

## 安装方式

安装在 `/opt/gamecore-certbot` 的 Python 3.10 虚拟环境中。云镜像默认的 pip 源是 HTTP，所以用 `PIP_CONFIG_FILE=/dev/null` 和 `--index-url https://pypi.org/simple --force-reinstall --no-cache-dir` 从官方 HTTPS 渠道重新安装了全部运行包。ACME 账户密钥、服务器私钥和环境文件都不导出到仓库。

## 调用方式

- 申请证书：`certbot certonly --preferred-profile shortlived --webroot --ip-address ...`。
- 续期：systemd timer 每小时运行 `renew --no-random-sleep-on-renew`，带 5 分钟错峰。
- 部署回调：检查证书剩余有效期、IP SAN 和密钥是否匹配，然后原子切换证书并重载 Nginx。证书发生变化时优雅重启 TLS 游戏节点。
- 代码入口：`deploy/scripts/deploy-ip-certificate.sh`、`deploy/systemd/gamecore-ip-renew.*`。

## 限制

- IP 证书有效期约 160 小时，80 端口必须保持可达才能续期。
- 续期流程通过了 dry-run，证书真实到期时的自动签发还没有发生过。
- 5.9 版本提示下一版将停止支持 Python 3.10，升级前要先迁移 Python 并回归，不能直接用 pip 自动更新。
- 注册时不提供邮箱，不向第三方传递玩家数据；CA 只验证公开的服务器 IP。
