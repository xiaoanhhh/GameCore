## 实际制品

`client` 使用 `com.badlogicgames.gdx:gdx:1.14.2`；`lwjgl3` 使用 `gdx-backend-lwjgl3:1.14.2`，运行时加入 `gdx-platform:1.14.2:natives-desktop`。字体扩展见 [FreeType](../FreeType/使用说明.md)。

规则模块不依赖 libGDX，这由 Gradle 依赖在编译期保证。

## 使用的接口

| 领域 | 接口 | 使用位置与注意事项 |
| --- | --- | --- |
| 应用生命周期 | `Game`、`ScreenAdapter`、`Lwjgl3Application`、`Lwjgl3ApplicationConfiguration` | `GameCoreClient` 切换页面；`Game` 不会自动释放所有 Screen |
| 多窗口 | `Lwjgl3Application.newWindow`、`Lwjgl3WindowConfiguration`、`Window.postRunnable/focusWindow/closeWindow`、`Lwjgl3WindowAdapter.focusLost` | 每个窗口有独立的 Stage、字体和纹理；失焦直接暂停所属页面；窗口句柄不进入规则层 |
| 界面 | `Stage`、`Table`、`ScrollPane`、`ButtonGroup`、`TextButton`、`Label`、`TextField`、`SelectBox`、`Slider`、`Dialog`、`InputMultiplexer` | Stage 在离开页面时释放；输入只在页面显示期间注册，并保留所属 Input 引用，解绑时不影响其他窗口 |
| 视口 | `FitViewport`、`ExtendViewport` | 大厅用 1280×720 设计视口；Snake 用纯 Java 的正方形布局 |
| 绘制 | `Batch`、`Texture`、`TextureRegion`、`ScreenUtils.clear` | `SnakeBoard`、`TankBoard`、格斗渲染器只读快照绘制；纹理由 `ClientAssetManager` 统一释放 |
| 地图 | `TmxMapLoader`、`TiledMap`、`TiledMapTileLayer` | 每窗口独占 `TiledMap`，切图和离页时释放；与纯 Java 碰撞格逐格核对 |
| 音频 | `Sound.play` | 遵循音量设置 |
| 验收 | `Gdx.graphics`、`Gdx.gl`、framebuffer `Pixmap`、`PixmapIO.writePNG`、`Gdx.app.exit` | 图形任务读取实际 framebuffer 截图；Pixmap 在 finally 中释放；调用 exit 不代表清理完成，要等后端返回 |

## 限制

- 没有使用 Box2D、gdx-tools、框架示例图或皮肤，也没有使用 `AssetManager` 异步加载。共享资源由 `ClientAssetManager` 集中管理。
- 规则不能随显示帧率推进，页面用固定步长时钟驱动。
- `SelectBox` 收起使用本版本未废弃的 `hideScrollPane`。
- JUnit 不能证明 OpenGL 可用，图形行为由真实窗口任务验证，见评测集。
- 框架自带的本地库和其他制品，在正式发行时要检查各自的许可。
