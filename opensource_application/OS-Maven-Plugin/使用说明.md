# OS Maven Plugin

| 项目 | 内容 |
| --- | --- |
| 制品 | `kr.motd.maven:os-maven-plugin:1.7.1` |
| 类型 | 构建工具依赖（OS Detector 传递引入） |
| 许可 | Apache-2.0，原文见 [LICENSE](LICENSE) |
| 来源 | [上游源码](https://github.com/trustin/os-maven-plugin/tree/os-maven-plugin-1.7.1) |

为 Gradle 插件提供操作系统和架构识别。本工程没有 Maven 构建，也不直接调用它的 Mojo 接口。它向下只解析出 `com.google.code.findbugs:jsr305:3.0.2`，不进入服务器的 `lib` 目录。

依赖链报告见 build-dependencies.txt。
