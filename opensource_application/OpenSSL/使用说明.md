# OpenSSL

| 项目 | 内容 |
| --- | --- |
| 版本 | WSL Ubuntu 22.04 的 OpenSSL 3.0.2（包版本 3.0.2-0ubuntu1.20） |
| 类型 | 本机命令行工具，不随发行包携带 |
| 许可 | 3.x 为 Apache-2.0，见[官方 LICENSE](https://github.com/openssl/openssl/blob/master/LICENSE.txt) |
| 来源 | [openssl/openssl](https://github.com/openssl/openssl) |

## 使用位置

- `tools/verify-linux-deployment.py` 调用 `openssl req`，生成两天有效、带 localhost/IP SAN 的回环测试证书。
- 运维说明用 `openssl rand` 生成服务密钥。

## 限制

- 程序本身的 TLS 由 Netty 和 JDK JSSE 实现，不使用 OpenSSL JNI 或 tcnative，没有 OpenSSL 的 Gradle 依赖。
- 测试私钥只写在 `.cache` 中，权限 0600，不提交也不分发。这种证书不能用于公网部署。
- 生产环境使用发行版的安全维护版本，并记录 `openssl version -a` 和 `dpkg-query` 结果。
