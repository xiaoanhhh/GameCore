# Tiled（地图格式）

| 项目 | 内容 |
| --- | --- |
| 类型 | 地图文件格式与可选的开发工具，不进入 Maven 类路径 |
| 格式 | TMX version 1.10 的有限正交、CSV、Point/矩形对象子集；参考的官方文档页面标示 Tiled 1.12.2 |
| 来源 | [官方项目](https://github.com/mapeditor/tiled)、[TMX 格式文档](https://docs.mapeditor.org/en/latest/reference/tmx-map-format/) |
| 上游许可 | [COPYING](https://github.com/mapeditor/tiled/blob/master/COPYING) 区分编辑器和插件的 GPL 与 libtiled 的 BSD 2-clause；[LICENSE.GPL](https://github.com/mapeditor/tiled/blob/master/LICENSE.GPL) 为 GPL v2 文本 |

项目没有安装、调用或打包 Tiled 编辑器，没有链接 libtiled，也没有复制它的源码。实际解析器是 JDK XML 和 libGDX 1.14.2。这里登记的编辑器许可不是本项目或原创地图的许可；如果将来分发编辑器或复制代码，要按具体组件重新核对。

## 使用位置

| 位置 | 作用 |
| --- | --- |
| `assets/maps/tank/*.tmx` | 原创标准地图，六层分离，可用 Tiled 打开 |
| `scripts/prepare-tank-maps.py` | 项目原创脚本，生成地图和原创几何 PNG，不调用 Tiled API |
| `game-tank/TmxArenaLoader` | 用 JDK XML 解析碰撞、出生点和玩法区域，不加载图片 |
| `client/tank/TankMapAsset` | 用 libGDX `TmxMapLoader` 加载视觉层，并做逻辑一致性检查 |
| `client/tank/TankBoard` | 从 `TiledMapTileLayer` 读取图块并绘制 |

## 限制

- 只支持有限、正交、方格、CSV 地图，不支持组层、无限块、压缩、GID 翻转和层偏移。
- 出生点使用 `heading` 属性，维修区是 `type=repair` 的矩形。
- 已验证地图的 JDK 解析、libGDX 加载和实际绘制。在 Tiled 编辑器中编辑并保存后的兼容性没有验证。
