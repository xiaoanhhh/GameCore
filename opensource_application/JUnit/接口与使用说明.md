# JUnit

| 项目 | 内容 |
| --- | --- |
| 版本 | Jupiter / BOM 5.14.2，Platform 1.14.2 |
| 类型 | 测试依赖，不进入应用运行时 |
| 许可 | EPL-2.0 |
| 来源 | [官方指南](https://docs.junit.org/5.14.2/user-guide/)、[官方源码](https://github.com/junit-team/junit-framework/tree/r5.14.2) |

## 接入方式

各模块的 `build.gradle` 用 BOM 对齐 Jupiter、Platform launcher 和引擎，根构建的 `useJUnitPlatform()` 负责发现测试。

## 使用的接口

| 接口 | 用途 |
| --- | --- |
| `@Test` | 普通测试 |
| `@ParameterizedTest` | 批量输入；`RegisteredGameContractTest` 用它遍历注册表中的每款游戏 |
| `@MethodSource` | 由方法提供参数 |
| `@NullAndEmptySource`、`@ValueSource`、`@CsvSource` | 空值、无效尺寸和帧率等边界输入 |
| `@TempDir` | 设置和成绩存储测试使用的临时目录 |
| `assertEquals`、`assertArrayEquals` | 比较配置、快照和字节 |
| `assertThrows` | 验证非法值被拒绝 |

HTML 和 XML 报告由 Gradle 输出到各模块的 `build` 目录。测试分层和运行命令见评测集。

API Guardian 和 OpenTest4J 是 JUnit 的测试支持依赖，分别登记。
