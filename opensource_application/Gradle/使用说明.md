## 工程接入

- 根目录的 `gradlew.bat`、`gradlew` 启动固定版本，不需要全局安装 Gradle。
- `settings.gradle` 管理模块和仓库，`build.gradle` 管理共有的编译约束，`gradle/libs.versions.toml` 管理依赖版本。
- `java-library` 提供编译和测试，`application` 提供 `run` 和分发任务，`useJUnitPlatform()` 启用 JUnit 5。
- `smokeTest` 是独立的 source set，用 `JavaExec` 验证图形运行，默认不加入普通 `build`。

```powershell
.\gradlew.bat clean build --console=plain
.\gradlew.bat :lwjgl3:test
.\gradlew.bat :lwjgl3:smokeTest
.\gradlew.bat :lwjgl3:run
.\gradlew.bat :lwjgl3:dependencies --configuration runtimeClasspath
```

## 限制

- Java 不一定继承 Windows 系统代理。需要代理时，只在本机用户的 `gradle.properties` 中设置，不写进工程共享配置。
- Gradle 自带的工具依赖不进入应用。应用的运行依赖以 `runtimeClasspath` 为准。
