# LWJGL

| 项目 | 内容 |
| --- | --- |
| 版本 | 3.3.3 |
| 类型 | 客户端运行依赖（`gdx-backend-lwjgl3:1.14.2` 传递引入） |
| 许可 | 主项目 BSD-3-Clause，原文见 [LICENSE.md](LICENSE.md) |
| 来源 | [官方仓库](https://github.com/LWJGL/lwjgl3/tree/3.3.3) |

## 作用

提供 OpenGL、GLFW、OpenAL 等原生绑定。模块包括 lwjgl、glfw、jemalloc、openal、opengl、stb，以及各桌面平台的 native classifier。

## 调用位置

业务代码通过 libGDX 间接使用。唯一的直接调用在测试中：`GameWindowSmokeTest` 用 `GLFW.glfwGetWindowAttrib` 读取 `GLFW_MAXIMIZED`，确认新窗口确实被创建并最大化。

## 限制

- 需要真实图形会话，DLL 加载受系统架构和安全软件影响。
- 图形验收禁用了音频，所以 OpenAL 没有测试过。
- LWJGL 绑定的底层原生项目有各自的许可，见制品 META-INF 和[第三方许可目录](https://github.com/LWJGL/lwjgl3/tree/3.3.3/doc)。BSD-3-Clause 不能代替这些组件的许可。
- gdx-liftoff 1.14.2.3 的模板把 LWJGL 约束到 3.4.3，主要是为了支持更新的 JDK。本项目使用 Java 21，保持 libGDX 后端声明的 3.3.3。升级要作为独立变更，重新验证窗口、输入、音频和打包。
