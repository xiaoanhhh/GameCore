# Git

| 项目 | 内容 |
| --- | --- |
| 版本 | 2.45.2.windows.1（开发机） |
| 类型 | 开发工具，不随应用分发 |
| 许可 | GPL-2.0，见[官方 COPYING](https://github.com/git/git/blob/v2.45.2/COPYING)；Windows 发行包内的工具可能有其他许可 |

项目根目录是唯一的 Git 仓库，不在子目录中再次初始化。构建产物和缓存由 `.gitignore` 排除，二进制的 Gradle Wrapper 要保留。

常用命令：`git status`、`git diff`、`git add`、`git commit`、`git log`。

本地提交不等于已有远程备份；没有 remote 和 push 时，代码仍然只在本机。
