# JCTools（Netty 内嵌）

| 项目 | 内容 |
| --- | --- |
| 版本 | 4.0.7 |
| 类型 | 内嵌在 `netty-common` 中，没有独立 JAR |
| 许可 | Apache-2.0，原文见 [LICENSE](LICENSE) |
| 来源 | [固定 tag](https://github.com/JCTools/JCTools/tree/v4.0.7) |

## 作用

Netty 内部使用的并发队列实现。包名已重定位到 `io.netty.util.internal.shaded.org.jctools`。

版本依据是 `netty-common-4.2.19.Final.jar` 内 `META-INF/maven/org.jctools/` 下的 `pom.properties`，核对记录见 embedded-jctools.txt。

## 使用位置

客户端和游戏节点都通过 Netty 间接使用。项目代码不调用它的接口，也不使用这些 shaded 类。实际调用的 Netty 接口见 [Netty 说明](../Netty/使用说明.md)。

## 限制

- Gradle 依赖树里看不到 JCTools，但它确实随 Netty 分发。升级 Netty 时要重新核对内嵌版本和归属。
- 发行包保留此 LICENSE；Netty 的 [NOTICE](../Netty/NOTICE.txt) 和 `license/LICENSE.jctools.txt` 保留改编归属。
- 分发检查见 distribution-check.json。
