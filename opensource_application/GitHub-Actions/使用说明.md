# GitHub Actions

| 项目 | 内容 |
| --- | --- |
| 配置 | `.github/workflows/build.yml` |
| 类型 | 持续集成配置 |

## 作用

在 push、PR 或手动触发时，用 Windows runner 和 Temurin JDK 21 运行 Gradle 构建、JUnit 和六项图形任务，并上传结果。

## 使用的 Actions

| Action | 许可 | 作用 |
| --- | --- | --- |
| [actions/checkout v4](https://github.com/actions/checkout/tree/v4) | MIT | 取得当前提交，关闭凭据持久化 |
| [actions/setup-java v4](https://github.com/actions/setup-java/tree/v4) | MIT | 准备 JDK 21 |
| [gradle/actions setup-gradle v4](https://github.com/gradle/actions/tree/v4) | MIT | 提供缓存和 Wrapper 校验 |
| [actions/upload-artifact v4](https://github.com/actions/upload-artifact/tree/v4) | MIT | 保存测试产物 |

## 限制

- 工作流还没有在托管环境中实际运行过，所以不算已通过。Windows runner 是否具备图形能力要看首次运行结果；如果失败，要保留报告并说明环境差异，不能静默跳过。
- 工作流只授予 `contents:read`。
- 目前使用官方主版本标签，没有固定到不可变提交。公开协作时可以进一步锁定 commit SHA。
