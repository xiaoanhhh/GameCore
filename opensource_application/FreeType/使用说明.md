# FreeType（libGDX 扩展）

| 项目 | 内容 |
| --- | --- |
| 制品 | `com.badlogicgames.gdx:gdx-freetype:1.14.2`、`gdx-freetype-platform:1.14.2:natives-desktop` |
| 类型 | 客户端运行依赖 |
| 许可 | Java 包装层为 Apache-2.0；原生 FreeType 是独立项目，见[官方说明](https://freetype.org/license.html) |

包装层的许可不能代替原生库的许可。

## 作用

让客户端用打包的中文字体绘制界面，不依赖系统字体。代价是增加了 native 依赖和字体图集内存。

## 调用方式

- `ClientAssetManager` 用 `FreeTypeFontGenerator` 读取 TTF，用 `FreeTypeFontParameter` 指定字号和字符表，`generateFont` 生成 `BitmapFont`。
- 每次生成后释放 generator。
- 启动时和窗口密度切档时各生成五种字号。
- `BitmapFont.getData().setScale` 维持逻辑尺寸，`setUseIntegerPositions(false)` 支持非整数像素比例。
- 更新页面样式后释放旧字体组，当前字体组在客户端退出时释放。

## 限制

图集密度越高，内存占用越大。项目使用 0.25 分档、稳定等待和最高 4 倍密度来控制生成成本。

真实窗口中验证了字体加载、逐字 `hasGlyph` 和多分辨率截图，见阶段 01 验证记录。原生库的精确版本和完整发行许可要以对应的 gdx native 包和上游源码核对，这里不作为正式发行审计结论。
