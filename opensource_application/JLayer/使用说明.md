# JLayer（libGDX 变体）

| 项目 | 内容 |
| --- | --- |
| 制品 | `com.badlogicgames.jlayer:jlayer:1.0.1-gdx` |
| 类型 | 客户端运行依赖（桌面后端传递引入） |
| 许可 | POM 声明 LGPL 2.1 |
| 来源 | [POM 中登记的上游](https://github.com/libgdx/jlayer-gdx) |

libGDX 音频层用它解码 MP3。项目不直接调用它的 API，项目素材中也没有 MP3 文件。

元数据来自实际解析的 Maven POM，见上级 `dependency-metadata.json`。

## 限制

- 该 JAR 没有内嵌 LICENSE。正式分发前要核对上游许可、源代码和分发要求，不能用 libGDX 的 Apache 许可代替。
- 图形验收禁用了音频，但它仍在运行包里。
