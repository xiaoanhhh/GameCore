# Python

| 项目 | 内容 |
| --- | --- |
| 版本 | Linux 实测 CPython 3.10.12；部署要求 Python 3.10+ |
| 类型 | 部署和验收工具，不打进发行包 |
| 许可 | Python Software Foundation License 2 及历史许可，见[官方 LICENSE](https://github.com/python/cpython/blob/main/LICENSE) |
| 来源 | [CPython](https://github.com/python/cpython) |

## 使用位置

| 脚本 | 作用 | 使用的标准库 |
| --- | --- | --- |
| `deploy/scripts/verify-release.py` | 校验发布包，拒绝链接和路径穿越 | tarfile、hashlib、pathlib、tempfile |
| `deploy/tests/`、`tools/verify-linux-deployment.py`、`tools/verify-systemd-local.py` | 本地测试和指标采集 | subprocess、urllib、json、unittest |
| `scripts/prepare-*.py` | 素材生成 | 见 [FontTools](../FontTools/使用说明.md) |

部署和验收脚本没有 pip 依赖。备份和服务启动不运行 Python 服务。

## 限制

- 解压限制为 256 MiB、4000 个条目。外部可信 SHA 和包内 Manifest 必须一致。SHA 校验不能证明发布者身份。
- 解释器依赖的 libc、压缩和 TLS 库由 Ubuntu 管理。部署时记录 `python3 --version`、`dpkg-query` 和包版权文件。
