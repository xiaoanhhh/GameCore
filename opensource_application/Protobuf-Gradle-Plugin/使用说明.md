## 调用位置

只有 `protocol/build.gradle` 应用这个插件。`protobuf.protoc.artifact` 显式固定为 4.34.2，`generateProto` 等任务接入正常的 Java 编译。不会使用本机任意的 `protoc`，也不向运行类路径注入 Gradle 插件。

## 传递依赖

`osdetector-gradle-plugin:1.7.3` → `os-maven-plugin:1.7.1` → `jsr305:3.0.2`，分别在独立目录登记。报告见 build-dependencies.txt。

## 限制

在 Gradle 9.8.0 和 Java 21 上可以正常生成、编译和测试。插件调用 `Configuration.setVisible` 会触发 Gradle 弃用警告，提示 Gradle 11 将移除。这个警告保留着，没有降低 `-Werror`，也不声称支持 Gradle 11。升级 Wrapper 前要复核插件兼容性。
