# 工具

本目录的脚本不进入游戏规则或生产运行时，只在显式执行时使用。脚本通过自身路径定位项目根目录，输出写到指定的报告或缓存目录。

| 工具 | 作用 | 运行条件 |
| --- | --- | --- |
| `run-online-multigame.py`、`online-tank-process-probe.py` | 由 Gradle 图形验收任务调用，启动本机服务器和两个客户端；只清理自己创建的进程 | 真实桌面图形会话 |
| `isolated-build.init.gradle` | 已有客户端窗口锁住 JAR 时，把构建输出隔离到 `.cache` 下，不需要结束正在运行的程序 | 任意 |
| `run-server-benchmark.py` | 本机负载测量编排；只连接回环地址 | 本机 |

性能数据只描述测量时的本机环境，不用于推算公网承载人数。
